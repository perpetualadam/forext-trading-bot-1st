# Future wheel verification

Do not run this procedure now.

After a reviewed lock exists, each distribution needs an exact name, version, filename, SHA-256, wheel tags, `Requires-Python`, metadata dependencies, marker result, target compatibility, native library requirements, origin, and a recorded integrity check. A missing compatible wheel fails the check. Source builds stay outside the first milestone unless a separate toolchain approval exists.

This procedure does not download, install, resolve, or create a wheelhouse by itself. Download remains a separate approval from the lock review.
