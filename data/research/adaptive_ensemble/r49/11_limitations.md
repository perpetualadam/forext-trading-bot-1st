# R.49 security limitations

The handoff is prepared and the connection is not. These limits stay in force.

- Broker-enforced read-only permission is `UNKNOWN`. The token may be able to trade.
- Hidden typing is not protection against Cursor, a terminal recorder, a debugger, or process-memory inspection.
- The approved place for a future entry is a window you open from the Windows Start menu, not Cursor's terminal. Even that window can be recorded.
- This build cannot connect. A later stage would have to add the HTTPS call after a new approval. Editing the flag yourself is not that approval.
- The application regression suite was not run. It imports modules that read the access token from the environment.
- Account contract fields remain `NOT_RETRIEVED`.
- The earlier ticket, including one pip displayed as £0.00, is still a rounded display and not a zero-risk proof.
- The financing panel rates from R.48 were not matched to an API field.
