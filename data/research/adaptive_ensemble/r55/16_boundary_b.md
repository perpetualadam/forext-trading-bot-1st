# Boundary B recommendation

Boundary B is not approved by this stage.

A later written approval would need to name a new executable hash before any real credential is entered. That later program would still be limited to one Windows Terminal session, opened from the Start menu, outside Cursor. Its order would be the preview, a local confirmation, the account identifier, hidden token entry, then at most two GET requests: instruments, then pricing, for the six approved pairs, with `includeHomeConversions=true`. Certificate checks, the five-second timeout, no redirects, and no retries would remain. The result would be the sanitised file only.

That approval would still exclude orders, trades, positions, account discovery, candles, streams, backtests, strategy activation, deployment, and rollback. Token permission would stay unknown unless the broker states it. Account home currency would stay `ACCOUNT_HOME_CURRENCY_API_UNVERIFIED` unless a permitted field establishes it.

No command in this directory starts that session.
