# Future approval checklist

The D.21 approval covers this planning record only. It does not authorise a network request.

A later read-only registry stage still needs an explicit approval that names:

- Registry hostname.
- Repository.
- Tag or digest.
- OCI platforms, both `linux/amd64` and `linux/arm64` if both are in that stage.
- Network endpoints.
- Authentication policy.
- HTTP methods.
- API paths.
- Timeouts.
- Response-size limits.
- Redirect policy.
- Retry policy.
- Evidence destination.
- Verification algorithm.
- Stop conditions F01–F20.

Until that list is approved, no destination is authorised.
