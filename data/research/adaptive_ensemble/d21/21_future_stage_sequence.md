# Future stage sequence

These stages are proposals. None starts from this record.

1. Read-only registry index and platform-manifest verification.
2. Runtime metadata for AMD64 and ARM64.
3. Python patch, ABI, distribution, and libc.
4. Dependency metadata and wheel compatibility.
5. Platform-specific dependency locking.
6. Artifact provenance and security review.
7. Candidate image builds.
8. Isolated runtime compatibility tests.
9. VPS hardware compatibility.
10. Production authority, safety, rollback, and deployment readiness.

Each stage needs its own approval.
